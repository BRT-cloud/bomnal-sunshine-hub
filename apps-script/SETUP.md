# 구글 스프레드시트 연동 가이드 (Google Sheets + Apps Script)

어떤 컴퓨터나 스마트폰에서 접속하든 동일한 링크와 목차가 표시되도록 구글 스프레드시트를 백엔드로 연결하는 방법입니다. (무료, 별도 서버 필요 없음)

---

## 1단계: 구글 스프레드시트 생성
1. [Google 스프레드시트](https://sheets.google.com)에 접속하여 **새 스프레드시트(빈 문서)**를 만듭니다.
2. 제목을 `봄날의 햇살 데이터`와 같이 알아보기 쉽게 지정합니다.

---

## 2단계: Apps Script 붙여넣기
1. 상단 메뉴에서 **확장 프로그램** > **Apps Script**를 클릭합니다.
2. 에디터에 기존 `function myFunction() {}` 내용을 지우고, 이 프로젝트의 [`apps-script/Code.gs`](./Code.gs) 파일의 전체 내용을 그대로 복사하여 붙여넣습니다.
3. 상단의 💾 **저장** 버튼(Ctrl+S)을 누릅니다.

---

## 3단계: 관리자 비밀번호 확인 (선택 사항)
- 기본 관리자 비밀번호는 **`0809`**로 설정되어 있습니다.
- 비밀번호를 다른 값으로 변경하고 싶다면:
  1. Apps Script 좌측 메뉴의 ⚙️ **프로젝트 설정**을 클릭합니다.
  2. 하단의 **스크립트 속성** > **스크립트 속성 추가**를 클릭합니다.
  3. 속성에 `ADMIN_PASSWORD`, 값에 원하는 비밀번호를 입력하고 저장합니다.

---

## 4단계: 웹 앱 배포 (가장 중요 ⭐)
1. 우측 상단의 파란색 **배포** > **새 배포**를 클릭합니다.
2. 왼쪽 톱니바퀴 아이콘 ⚙️을 누르고 **웹 앱**을 선택합니다.
3. 다음과 같이 설정합니다:
   - **설명**: `봄날의 햇살 v1`
   - **다음 사용자로 실행**: **나 (내 이메일 계정)**
   - **액세스 권한이 있는 사용자**: **모든 사용자 (Anyone)** ⭐ (*로그인 없이 누구나 링크를 읽을 수 있도록 필수 설정*)
4. **배포** 버튼을 누릅니다. (첫 배포 시 '액세스 승인' 창이 뜨면 구글 계정으로 로그인 후 고급 > 이동을 눌러 허용해줍니다)
5. 배포 완료 창에 표시되는 **웹 앱 URL** (예: `https://script.google.com/macros/s/AKfycb.../exec`)을 복사합니다.

---

## 5단계: 웹앱에 연동하기

### A. 로컬(내 컴퓨터)에서 테스트할 때
프로젝트 루트 경로에 `.env` 파일을 만들고 아래와 같이 복사한 URL을 입력합니다:
```env
VITE_SHEETS_API_URL=https://script.google.com/macros/s/AKfycb.../exec
```

### B. Vercel에 배포할 때
1. Vercel 대시보드에서 해당 프로젝트의 **Settings** > **Environment Variables**로 이동합니다.
2. Key에 `VITE_SHEETS_API_URL`
3. Value에 복사한 웹 앱 URL을 넣고 **Save**합니다.
4. **Deployments** 탭에서 **Redeploy**를 누르면 끝!

---

## 💡 유용한 팁
- 관리자 모드(비밀번호: `0809`)로 로그인하면 상단에 **"현재 브라우저에 저장된 링크를 구글 시트로 전송"** 버튼이 나타납니다. 기존에 등록해두신 링크들을 클릭 한 번으로 시트에 옮길 수 있습니다.
- 구글 스프레드시트에서 직접 링크나 카테고리를 편집하셔도 웹앱에 즉시 반영됩니다.
